Configuration (1 fois)

Pour que cette page lise ta fiche et crée tes rédactions dans ton repo privé, elle a besoin d'un token GitHub.

Crée un fine-grained PAT :

  1. Ouvre github.com/settings/personal-access-tokens/new
  2. Nom : agreg-mobile, expiration : 1 an
  3. Repository access : Only select repositories → choisis agreg
  4. Permissions :
    • Contents → Read
    • Issues → Read and write
  5. Génère, copie, colle ci-dessous.
